# REDOVA email assets

These small raster assets are packaged with `@redova/integrations` and attached inline by the email renderer. They do not require public hosting.

- `redova-logo-light.png`: optimized copy of the original official light-background logo at `apps/web/public/brand/logos/redova-horizontal-light.png`. The mark and lettering were not generated again.
- `account-security-light.jpg`: decorative light security illustration generated with the built-in image tool, then resized and compressed for email. It contains no required message content.

See [the design, previews, generation prompt and validation notes](../../../../docs/email/README.md).
